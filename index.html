The package

What you get

A language, a runtime, a compiler and a desktop IDE — all in a single Windows installer.

01

A real language engine

Nova reads your file into tokens, a syntax tree and a typed program. No string rewriting — and when something is wrong it shows the line, the exact spot, and a hint.

02

Types that help

Write let score: Int = 100 when the type matters, or let Nova infer it. String? values must be checked before use, and mistakes are caught before the program starts.

03

Collections that work

Lists, maps and sets with the operations programs actually need: sort, filter, map, reduce, join, slices and short lambdas like n => n * 2.

04

Maths built in

Statistics, trigonometry, matrices and vectors — plus a symbolic engine: simplify, derivative, integral and equation solving, exactly where it can be.

05

Nova Studio IDE

A native desktop editor with a file explorer, syntax highlighting, code completion, Run, Compile and Build EXE, plus an offline AI assistant.

06

Windows programs & overlays

Build a standalone EXE with nothing else installed, or draw into a window and run transparent, always-on-top, click-through overlays.

New in 0.4

Everything the language learned

0.4 is a new engine underneath the same beginner-friendly words.

  • Modern syntax. if / else if / else, for i in 1..10, while, break and continue — with the old when, each and stop still accepted.
  • Static types with inference. Annotations are promises the checker keeps; unannotated values are inferred. let tag: String? = nothing works with tag ?? "none" and if tag != nothing.
  • Functions with defaults, recursion and lambdas. fn area(w: Float, h = 2) -> Float, and one-line n => n * 2 functions for filter, map and sort.
  • Helpful errors. Every diagnostic names the file, line and column, prints the source line under a caret, and suggests a fix — including did you mean 'push'?.
  • A compiler that agrees. Compiled programs print exactly what the interpreter prints, maths engine included; the memory builtins are still refused on purpose.
maths.nova
let values = [4, 8, 12, 16]
show math.mean(values)        # 10
show math.stddev(values)      # 4.472135955

let x = solve(3*x + 9 == 24)
show x                        # 5
show math.simplify("2*x + 3*x")        # 5*x
show math.derivative("x^3 + 2*x", "x") # 3*x^2 + 2
show math.integral("x^2", 0, 3)       # 9

show math.matmul([[1, 2], [3, 4]],
              [[5, 6], [7, 8]])   # [[19, 22], [43, 50]]

Up and running in three steps

The installer sets up the IDE, the console interpreter, your PATH, and .nova file associations.

Run the installer

Download NovaSetup.exe and run it. It installs Nova Studio and the command tools to %LOCALAPPDATA%\Nova and puts that folder first on your user PATH.

Open a new CMD window

Type nova to launch the IDE. Existing terminal windows keep the old PATH, so the new window matters.

nova

Write and run your first program

Create a file named main.nova, then run it with the console interpreter — or press Run inside Nova Studio.

novac main.nova
