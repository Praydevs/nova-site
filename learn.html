Lesson 1

Your first program

Nova programs live in files that end in .nova. You do not wrap code in def main() or import anything — a Nova file runs from its first line to its last.

Create a file called main.nova and type this:

main.nova
show "Hello, Nova!"
Hello, Nova!

Run it from the terminal, or by pressing Run in Nova Studio:

Command Prompt
novac main.nova
novac is the Nova console. It runs any .nova file; nova opens the Nova Studio IDE.
Lesson 2

Output with show

show prints a value. It takes any expression — a literal, a variable, a calculation, or a function call.

main.nova
show "My name is Nova"
show 2 + 3
show "total: " + str(2 * 5)
My name is Nova 5 total: 10

Text joins with +. When one side is a number, convert it with str() first — Nova does not silently mix text and numbers.

Reading input

input(prompt) reads one line from the person using the program and returns it as text. Interactive programs — a calculator, a menu, a form — all start here.

calculator.nova
show "Welcome to the Calculator!"
let a = int(input("First number: "))
let b = int(input("Second number: "))
show "sum = " + str(a + b)
Welcome to the Calculator! First number: 6 Second number: 7 sum = 13
Where the typing happens: in Nova Studio each input() opens a small input dialog; under novac you type straight into the terminal. Wrap the text in int() so the maths works.
Older code may say print or say. Those still work for old examples, but show is the real Nova word. Use it in new programs.
Lesson 3

Variables, types and inference

let creates a variable and gives it a value. Most of the time you write no type at all — Nova infers it from the value. When the type matters, write it after a colon: Int, Float, String, Bool, List<T>, Map<K, V>, Set<T> or Nothing.

main.nova
let player = "Ace"                # inferred: String
let score: Int = 100           # written on purpose
let accuracy: Float = 98.5
let active: Bool = true

score = score + 25

show player + " scored " + str(score)
show "accuracy: " + str(accuracy)
Ace scored 125 accuracy: 98.5

To change a variable you just assign to it again. A written type is a promise: Nova checks it before the program runs, so this never gets the chance to go wrong:

main.nova
let score: Int = "high"
main.nova:1:18: error: expected Int, found String 1 | let score: Int = "high" | ^ hint: change the annotation, or assign a value of the annotated type
Inferred variables stay flexible. A variable with no written type takes the type of its value and can hold a different kind later; an annotated one keeps the type you promised, and score = "high" on an Int is reported as an error.
Lesson 4

Numbers, text and operators

Nova handles numbers and text (called strings) natively.

operators
# arithmetic
show 10 + 4      # 14
show 10 - 4      # 6
show 10 * 4      # 40
show 10 / 4      # 2.5
show 10 div 4    # 2   whole-number division
show 10 mod 4    # 2   remainder
show 2 ^ 5       # 32  power

# text
let a = "Nova"
let b = "Studio"
show a + " " + b   # Nova Studio
show a.length       # 4
show a.upper()      # NOVA
show "a,b,c".split(",")   # [a, b, c]
  • div divides and keeps only the whole number; mod gives the remainder (handy for "every 3rd item" tests).
  • ^ raises to a power — it is not XOR.
  • Convert with str(), int(), float(), round(); measure with len() or .length.
  • Text has members too: upper, lower, trim, split, replace, contains, starts_with, ends_with, repeat, to_int, to_float.
Lesson 5

Booleans and nothing

Two truth values — true and false — plus nothing, which means "no value at all" (like an empty result).

main.nova
let ready = true
let score = 10

show score > 5        # true
show score == 10      # true  (two equals signs!)
show ready && score > 5   # true  (AND)
show !ready            # false (NOT)

let missing = nothing
show missing
true true true false nothing
= assigns, == compares. Writing if score = 10 is a mistake — use == to ask a question.

Combine tests with && (and), || (or) and ! (not).

Values that might be nothing

A type ending in ? may hold nothing. Nova makes you deal with that before using the value: give a fallback with ??, or check it first with != nothing.

main.nova
let tag: String? = nothing

show tag ?? "untagged"          # untagged

if tag != nothing {
    show tag.upper()             # only runs when there is text
}
untagged

Using a nullable value directly is an error, not a surprise at runtime: show tag.length reports this value might be nothing and suggests both fixes.

Lesson 6

Conditions with if / else if / else

if runs a block only if its condition is true. else if tries another test, and else is the fallback. Blocks use curly braces { } — indentation is for readability, not grammar.

main.nova
let health = 45

if health > 60 {
    show "healthy"
} else if health > 30 {
    show "wounded"
} else {
    show "critical"
}
wounded

Chain as many else if branches as you need, then finish with a plain else if you want a default.

Choosing between two values? A one-line ternary works too: let label = health > 30 ? "alive" : "down".
Lesson 7

Loops: for and while

for ... in ... walks over a range, a list, a map or a piece of text. while repeats until its condition turns false.

for over a range
# 1..5 means 1, 2, 3, 4, 5 — both ends included
for number in 1..5 {
    show number
}

# a step lets you count by twos
for even in 0..6 step 2 {
    show even
}
1 2 3 4 5 0 2 4 6
while
let count = 0
while count < 3 {
    show count
    count = count + 1
}
0 1 2

for also walks collections, and a map hands out its names and values two at a time:

walking data
for name in ["Ace", "Nova"] {
    show name
}

for letter in "Nova" {
    show letter
}

let scores = {"alex": 10, "sam": 7}
for name, points in scores {
    show name + " -> " + str(points)
}
Ace Nova N o v a alex -> 10 sam -> 7
Always move toward the exit. If a while condition never becomes false the loop runs forever. Nova caps how many iterations and statements it will execute so a runaway program stops with an error instead of freezing your machine.
Lesson 8

break and continue

Inside a loop, break leaves immediately and continue jumps to the next turn.

main.nova
for n in 1..10 {
    if n == 4 {
        continue         # don't print 4
    }
    if n == 7 {
        break            # leave the loop entirely
    }
    show n
}
1 2 3 5 6

Using break or continue outside a loop is an error — Nova will tell you so instead of doing something surprising. The older words stop and skip mean the same two things.

Lesson 9

Functions and lambdas

fn names a reusable block; return sends a value back to the caller. Parameters and the result can carry types, and a parameter can have a default.

main.nova
fn double(value) {
    return value * 2
}

fn grade(score: Int) -> String {
    if score >= 90 {
        return "A"
    }
    return "keep going"
}

fn greet(name, greeting = "Hello") -> String {
    return greeting + ", " + name + "!"
}

# a function may call itself
fn fib(n: Int) -> Int {
    if n < 2 {
        return n
    }
    return fib(n - 1) + fib(n - 2)
}

show double(21)          # 42
show grade(95)           # A
show greet("Nova")        # Hello, Nova!
show greet("Nova", "Hi") # Hi, Nova!
show fib(10)             # 55
42 A Hello, Nova! Hi, Nova! 55
  • A function with no return gives back nothing.
  • Parameters are local — changing them inside does not change the caller's variable.
  • Define a function before you call it; passing the wrong number of arguments is reported with the parameter names.
  • give is the older word for return and still works.

Short functions

A one-line function is written with =>. That is what filter, map and sort expect:

main.nova
let square = n => n * n
show square(9)                        # 81

show [1, 2, 3, 4].filter(n => n > 2)  # [3, 4]
show [1, 2, 3].map(n => n * 2)      # [2, 4, 6]
81 [3, 4] [2, 4, 6]
Lesson 10

Lists, maps and sets

Keep several values together in a list (ordered, indexed from 0), look values up by name in a map, or keep one of each value in a set.

lists
let players = ["Ace", "Nova", "Rex"]
players.push("Kit")

show players[0]           # Ace
show players[-1]          # Kit   (from the end)
show players.length       # 4
show players.first        # Ace
show players[1:3]         # [Nova, Rex]
show players.contains("Rex")   # true
show players.index_of("Nova")  # 1
show players.join(", ")      # Ace, Nova, Rex, Kit
Ace Kit 4 Ace [Nova, Rex] true 1 Ace, Nova, Rex, Kit
working on a list
let numbers = [10, 20, 30]
numbers.push(40)

show numbers.filter(n => n > 15)              # [20, 30, 40]
show numbers.map(n => n * 2)                  # [20, 40, 60, 80]
show numbers.reduce((total, n) => total + n, 0) # 100
show numbers.sum()                            # 100
show numbers.sort()                           # [10, 20, 30, 40]
show reversed(numbers)                      # [40, 30, 20, 10]
show numbers.unique()                         # [10, 20, 30, 40]
show [1, 2] + [3]                          # [1, 2, 3]
[20, 30, 40] [20, 40, 60, 80] 100 100 [10, 20, 30, 40] [40, 30, 20, 10] [10, 20, 30, 40] [1, 2, 3]
maps and sets
let scores = {"alex": 10, "sam": 7}
scores.set("kim", 4)

show scores["alex"]              # 10
show scores.get("nobody", 0)      # 0    (no error)
show scores.has("sam")            # true
show scores.keys                  # [alex, sam, kim]

let tags = {"new", "old", "new"}
tags.add("sale")
show tags.length                  # 3
show tags.has("old")              # true
10 0 true [alex, sam, kim] 3 true

Everything is checked: reading past the end of a list, asking a map for a key that is not there, or pushing text into a list of numbers is reported with the line and a hint rather than quietly returning junk.

Lesson 11

The maths library

Mathematics ships with the language as math. Statistics, rounding, powers, trigonometry, logarithms, integers and matrices are all there — no imports, no packages.

statistics
let values = [4, 8, 12, 16]

show math.mean(values)       # 10
show math.median(values)     # 10
show math.mode([1, 1, 2, 2]) # [1, 2]
show math.variance(values)   # 20
show math.stddev(values)     # 4.472135955
show math.spread([4, 8, 12]) # 8
10 10 [1, 2] 20 4.472135955 8
numbers and angles
show math.sqrt(144)        # 12
show math.factorial(6)     # 720
show math.gcd(48, 180)      # 12
show math.lcm(4, 6)         # 12
show math.is_prime(97)      # true
show math.fibonacci(10)    # 55
show math.clamp(15, 0, 10)   # 10
show math.round(2.567, 2)   # 2.57
show math.sin(math.pi / 2)   # 1
show math.log10(1000)      # 3
show math.degrees(math.pi) # 180
12 720 12 12 true 55 10 2.57 1 3 180
matrices and vectors
let a = [[1, 2], [3, 4]]
let b = [[5, 6], [7, 8]]

show math.matmul(a, b)          # [[19, 22], [43, 50]]
show math.transpose(a)          # [[1, 3], [2, 4]]
show math.determinant(a)        # -2
show math.dot([1, 2, 3], [4, 5, 6]) # 32
show math.cross([1, 0, 0], [0, 1, 0]) # [0, 0, 1]
show math.norm([3, 4])           # 5
[[19, 22], [43, 50]] [[1, 3], [2, 4]] -2 32 [0, 0, 1] 5
Lesson 12

Solving and symbolic maths

The solve keyword solves an equation with one unknown, right inside your program. Use it as a statement to print the answer, or as an expression to keep the value.

main.nova
solve 2*x + 4 = 14
solve x^2 = 9

let x = solve(3*x + 9 == 24)
show x                       # 5

let price = 9                # names in the program are known values
let y = solve(3*y + price == 24)
show y                       # 5
x = 5 x = -3 or x = 3 5 5

Expressions as text

math.simplify, derivative, antiderivative and integral take maths written as text and work on it exactly, using fractions — 2*x + 3*x really is 5*x, not 5.0*x.

symbolic.nova
show math.simplify("2*x + 3*x")        # 5*x
show math.simplify("(x + 1)^2")        # x^2 + 2*x + 1
show math.derivative("x^3 + 2*x", "x") # 3*x^2 + 2
show math.antiderivative("x^2", "x")  # (1/3)*x^3
show math.evaluate("2*x + 1", {"x": 3}) # 7

show math.integral("x^2", 0, 3)       # 9     exact for polynomials
show math.integral("sin(x)", 0, math.pi) # 2 (numerical: Simpson's rule)
show math.derivative_at("x^2", "x", 3)   # 6

show math.solve("x^2 = 9")              # [-3, 3]
show math.solve_system(["x + y = 3", "x - y = 1"]) # {x: 2, y: 1}
5*x x^2 + 2*x + 1 3*x^2 + 2 (1/3)*x^3 7 9 2 6 [-3, 3] {x: 2, y: 1}
  • Linear and quadratic equations with one unknown are solved exactly; quadratics return both real roots, or nothing when there are none.
  • math.solve_system solves linear systems and returns a map of the answers.
  • Integrals and slopes are exact for polynomials and numeric otherwise; sin, cos and pi are available inside the text.
Lesson 13

Drawing on a canvas

Nova can open a window and draw into it. Call canvas() first, draw as much as you like, then present() to show the result.

picture.nova
canvas(500, 300, "My picture")

rect(20, 20, 160, 90, "#4f9dff")
circle(300, 150, 55, "#3ddc97")
line(20, 250, 480, 250, "#ffc861", 3)
draw_text(28, 44, "Hello, Nova", "white", 24)

present()

Shapes take x, y, a size, and a colour — a hex value like #4f9dff or a name like "red". Press Escape to close the window.

Drawing is ordinary Nova, so the maths engine comes along for free:

curve.nova
canvas(600, 200, "Sine wave")

for x in 0..600 step 4 {
    let y = 100 + 80 * math.sin(x / 40)
    circle(x, y, 2, "#3ddc97")
}

present()
Drawing needs a real desktop. Tkinter must be available and there must be a screen to draw on, so this will not work over SSH or in a headless session.
Lesson 14

Overlays

An overlay() window is frameless, always on top, and colour-keyed to full transparency — so only what you draw shows, floating over whatever is beneath it. Combined with refresh() it becomes a live loop.

loop.nova
overlay(400, 200, 40, 40, 0.8, "HUD")

while true {
    clear_canvas()
    rect(20, 20, 120, 40, "#3ddc97", false)
    draw_text(30, 32, "live", "white", 18)
    refresh(20)          # keep it alive ~20ms per frame
}
  • refresh(ms) keeps the window alive and returns false once it has been closed — use that to break the loop.
  • click_through() makes the overlay ignore the mouse, so it never blocks the window underneath.
  • rect(..., false) draws an unfilled outline instead of a solid block.
  • move_overlay(x, y) repositions it and hide_overlay() hides it.
  • window_bounds(pid) returns [x, y, width, height] so you can line the overlay up exactly over another program's window.
The pattern is always: draw → refresh(20) → repeat, and stop when refresh() returns false.
Lesson 15

Processes and memory

Nova can find a running program and read from it. The single most useful function is pid(), which returns the process ID of a running executable.

What a PID is. A PID is the number Windows gives a running process — it is not a memory address. To get one, start the program first, then look it up. You can also see PIDs in Task Manager → Details.
main.nova
# first matching process
show pid("RobloxPlayerBeta.exe")

# every matching process, as a list
show pids("chrome.exe")

# where the program was loaded in memory
let id = pid("notepad.exe")
show module_base(id)
10712 [4820, 9134] 140735218601984

The read helpers are all read-only and inherit your operating system's permissions:

  • read_memory(pid, address, count) — 1 to 4096 bytes, returned as numbers 0–255.
  • read_pointer(pid, address) — 8 bytes as one whole number.
  • read_float(pid, address) — 4 bytes as a decimal number.
  • read_text(pid, address, count) — up to count bytes of text, stopping at the first NUL.
  • read_pointers(pid, address, count) and read_floats(pid, address, count) — many values in one read, which is what keeps a live overlay's frame time down.
  • module_base(pid) — the load address of the main executable, or of a named module such as ntdll.dll.
Read only what you own or are permitted to inspect. Pass the PID as pid and the address as address — they are different arguments. These builtins work on Windows and Linux and are rejected by the compiler, so run such programs with novac yourfile.nova. Nova never writes to another process's memory.

A few more useful builtins: abort(msg) stops with an error message and exit status 1, sleep(seconds) pauses for up to 60 seconds, and tan(radians) is there for projection maths.

Lesson 16

Building a standalone EXE

Turn a Nova program into a single .exe that runs on a machine with nothing else installed.

The easy way — inside Nova Studio, press Build EXE, choose where to save, and the IDE handles the packaging.

What Build EXE does — it checks your source first and reports any Nova errors with line numbers, then produces a single self-contained executable in the location you chose. Double-click it like any other Windows program.

Not every program can be compiled. The compiler deliberately refuses the process and memory builtins. Programs that use pid(), read_memory() and friends run with novac yourfile.nova instead — those helpers are available there and not in compiled output, on purpose.

Next steps

Where to go next

You've covered the whole language. Here's how to keep going:

  • Read the errors. Every mistake names the file, the line and the column, shows the source under a caret, and usually suggests the fix — including did you mean 'push'? and did you mean 'score'?
  • Create a solution. In Nova Studio choose New Solution, pick a parent folder, name it, and select a base, print-to-world, or empty starter project.
  • Use the assistant. Nova Assist on the right can explain errors, propose edits (reviewed as a diff before they're saved) and suggest commands for you to approve.
  • Open a folder you already have. Open Folder reads a .nova-solution manifest if one is present and opens main.nova.
  • Read the source. tour.nova is a guided tour of the language that doubles as a smoke test, hello.nova is a short working example, and roblox.nova is a complete program that combines process lookups, drawing and a live overlay.
