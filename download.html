How to install Nova

Five steps from download to your first running program.

Download the installer

Click NovaSetup.exe above and keep the file. Windows may show SmartScreen for an unsigned app — choose More info → Run anyway if you trust the source you downloaded it from.

Run it

Double-click NovaSetup.exe. It copies Nova Studio, the nova launcher and the novac interpreter to %LOCALAPPDATA%\Nova, adds that folder to the front of your user PATH, and associates .nova files with the Nova icon.

Open a new CMD window

Windows passes PATH to a terminal when it starts, so a window you already had open will not see Nova yet. Close the old one and open a fresh Command Prompt.

Launch the IDE

Type the command and press Enter. Nova Studio opens as a normal desktop window.

nova

Run a program

Write a file called main.nova and run it from the console, or press the Run button inside Nova Studio.

novac main.nova

How to download the IDE

Nova Studio is the desktop editor. There are three ways to get it — pick whichever fits you.

Option 1 — With the installer

The easiest route. Run NovaSetup.exe and the IDE is installed, on your PATH, and registered for .nova files automatically.

# after installing
nova

Option 2 — Portable EXE

Download NovaStudio.exe and double-click it. Nothing is installed and nothing touches your PATH — put it anywhere, including a USB stick.

Download NovaStudio.exe

Option 3 — Console only

Just want to run .nova files from a terminal? The console interpreter does that with no IDE and no install — put nova.exe anywhere.

nova.exe main.nova

Download nova.exe

What's inside the IDE: a code editor with Nova syntax highlighting and inline completion, a solution/file explorer with right-click actions, Run, Compile and Build EXE, an output panel for errors, and the Nova Assist chat panel (offline model plus web search) on the right.

Command line

Everything Nova does is also available from a terminal — no IDE required. These commands come with the installer and cover interactive programs, including ones that read input.

Command Prompt
# open the Nova Studio IDE
nova

# run a Nova program
novac hello.nova

# or open the interactive prompt
novac

# run a program that asks for input
novac calculator.nova

# compile a program to Python
novac --help
Use novac for process and memory programs. Programs that call pid(), read_memory() or the other process builtins run directly in the interpreter — the compiler leaves those out of compiled output on purpose.

Verify your install

Run these three checks in a new CMD window.

Command Prompt
# the IDE should open a window
nova

# the interpreter should print its version banner
novac

# a real program should run
novac main.nova
Nova v0.4 — type 'exit' to quit
Getting 'nova' is not recognized? You opened a CMD window that predates the install. Close it completely and open a new one. If it still fails, check that %LOCALAPPDATA%\Nova is first in your user PATH, then reopen the terminal.
